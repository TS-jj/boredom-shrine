# 无聊神社 · ひまつぶし神社

一个给朋友做的单文件小工具。摇一支御籤，抽到哪件就做哪件。

## 怎么用

打开 `index.html` 就行（或直接访问线上链接）。零依赖、零构建、单个文件。

## 里面有什么

- **御籤抽签** —— 点签筒摇一支，六档吉凶（大吉 6% / 中吉 14% / 小吉 20% / 吉 28% / 末吉 20% / 凶 12%）
- **经验值升级** —— 完成任务拿经验，从「見習い」一路升到「仙人」，共 7 级
- **成就系统** —— 11 个成就
- **今日运势** —— 每天一次的日语签文 + 幸运色 + 幸运物
- **連続参拝** —— 连续天数 + 最近 28 天参拝日历
- **朝・昼・夜** —— 页面按打开时间自动换配色与任务池
- **音效** —— Web Audio 现场合成，不依赖任何音频文件
- **清空记录** —— 页脚按钮，两段式确认

进度存在浏览器 `localStorage`，每个人各存各的。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（Public）
2. 把本目录推上去：

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`
